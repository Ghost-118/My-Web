# 🌐 Front-End Web Development Compilation Page

Página web responsiva que recopila recursos educativos y tutoriales en video sobre los pilares fundamentales del desarrollo web front-end: **HTML**, **CSS** y **JavaScript**.

El proyecto está diseñado con una interfaz moderna en modo oscuro, estilos dinámicos e integración de reproductores embebidos de YouTube.

---

## 🌐 Demo en Vivo

Puedes ver la página publicada en GitHub Pages:
👉 **[https://ghost-118.github.io/My-Web/](https://ghost-118.github.io/My-Web/)**

---

## 🚀 Características

* **Diseño Responsivo:** Adaptado para una visualización óptima en dispositivos móviles y de escritorio.
* **Interfaz Tema Oscuro:** Estilizada con una paleta de colores moderna (`#0f172a` y `#1e293b`).
* **Secciones Interactivas:** Efectos dinámicos al pasar el cursor (*hover*) sobre las tarjetas de contenido mediante JavaScript.
* **Contenido Embebido:** Integración de reproductores de video mediante etiquetas `<iframe>`.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructuración semántica de la página.
* **CSS3:** Estilos visuales, diseño flex/grid responsivo y animaciones.
* **JavaScript (ES6):** Manejo de eventos del DOM y efectos de interacción.
